# Robo Cat Ears mobile app

Flutter phone app. Project docs live in `docs/`:

- `docs/agents/`: read every file here before starting work in this repo.
- `docs/adrs/`: architectural decision records. Check them before changing architecture; record a new decision here.
- `docs/maps/`: wayfinding maps, one per effort. Read the map before working one of its tickets.
- `docs/research/`: research output. Look here before researching a topic; write new findings here.
- `docs/issue-tracker.md`: read before reading, creating, or updating issues.

Each `docs/` subdirectory's `README.md` holds its naming and format rules; follow them when adding a doc there.
