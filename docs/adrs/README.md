# Architectural decision records

One decision per file, named `NNNN-<decision-slug>.md`, numbered sequentially from `0001`.

Each ADR has these sections:

- **Status**: Proposed, Accepted, or Superseded by ADR NNNN.
- **Context**: the forces and constraints behind the decision.
- **Decision**: what was chosen.
- **Consequences**: what gets easier or harder as a result.

Once an ADR is accepted, leave its decision as written. To change course, add a new ADR and mark the old one superseded.
